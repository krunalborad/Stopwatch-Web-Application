# ⏱️ Stopwatch Web Application

A simple and responsive **Stopwatch Web Application** built using **HTML, CSS, and JavaScript**. It allows users to **start, pause, reset, and record lap times** with a clean and modern user interface.

## 🚀 Features

- ▶️ Start the stopwatch
- ⏸️ Pause the stopwatch
- 🔄 Reset the stopwatch to zero
- 🏁 Record multiple lap times
- 🎨 Modern UI with a gradient background
- 📱 Fully responsive design

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive layout
- **JavaScript (Vanilla JS)** – Stopwatch functionality and user interactions

## 🧠 How It Works

- The stopwatch uses `setInterval()` to update the timer every second.
- Time is tracked in **hours, minutes, and seconds**.
- The **Start** button begins the timer.
- The **Pause** button temporarily stops the timer without resetting the elapsed time.
- The **Lap** button records the current stopwatch time and displays it in a list.
- The **Reset** button stops the timer, clears all recorded lap times, and resets the stopwatch to `00:00:00`.

## ✅ Conclusion

This **Stopwatch Web Application** demonstrates the fundamentals of front-end web development by combining **HTML**, **CSS**, and **JavaScript** to create a functional and interactive project. It provides an intuitive user experience with essential stopwatch features, a responsive design, and a modern interface. This project is an excellent example for beginners to understand JavaScript timing functions, DOM manipulation, and event handling while building a practical real-world application.
