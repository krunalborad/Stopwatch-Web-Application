⏱️ Stopwatch Web Application
A simple and responsive Stopwatch Web Application built using HTML, CSS, and JavaScript.
It allows users to start, pause, reset, and record lap times with a clean and modern UI.
🚀 Features
▶️ Start the stopwatch
⏸ Pause the stopwatch
🔄 Reset time to zero
🏁 Record multiple lap times
🎨 Modern UI with gradient background
📱 Fully responsive design
🛠️ Technologies Used
HTML5 – Structure of the application
CSS3 – Styling and layout
JavaScript (Vanilla JS) – Stopwatch logic and interactions
🧠 How It Works
- The stopwatch uses setInterval() to update time every second.
- Time is stored in hours, minutes, and seconds.
- The Lap button stores the current time into a list.
- The Reset button clears everything and stops the timer.
